# WallShift

Flutter wallpaper rotation with a native Android background engine.

## Features (v1.2 — Phase A)

- Auto-rotate on **screen wake** + timed AlarmManager + WorkManager watchdog
- **Crop / fit** — swipe through all photos, skip, add once
- **Themes:** Ember, Glass (blur cards), Light, AMOLED
- **Offline packs:** Motivation, Faith, Focus, Calm, Dark Aesthetic
- **Blur & dim** for icon readability
- **Hide app icon** (reopen from notification)
- **Glass home widget** — preview, Change now, Start/Pause
- **Launcher shortcuts** — long-press icon: Change now / Toggle / Packs

Video live wallpapers and a full glass system launcher are planned as later add-ons.

## Install from phone

1. Repo → **Actions** → **Build APK** → latest green run
2. **Artifacts** → **wallshift-apk** → download → install `app-release.apk`

### Add the widget (POCO / HyperOS)

1. Long-press home screen → **Widgets**
2. Find **WallShift**
3. Place the glass control card

### Shortcuts

Long-press the WallShift app icon → Change now / Toggle / Packs.

## Privacy

Photos and packs stay on-device. No account. Packs are rendered offline.
